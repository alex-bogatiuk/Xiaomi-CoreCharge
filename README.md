# Xiaomi CoreCharge

**Протестировано для ноутбуков: Redmibook Pro 14 2025 (Ultra 7 255H 32+1T) / Xiaomi Book Pro 14 2026 (Ultra x7 358H 32+1T)**

🚀 **[Скачать готовую версию (.zip)](https://github.com/alex-bogatiuk/Xiaomi-CoreCharge/releases/latest)** — запуск без необходимости компиляции.

## Описание
**Xiaomi CoreCharge** — системная утилита для ноутбуков Xiaomi и Redmi, предназначенная для управления аппаратным контроллером (Embedded Controller, EC). Программа позволяет ограничивать уровень заряда аккумулятора, переключать тепловые режимы процессора, а также обеспечивает интеграцию с системным треем Windows и экранную OSD-индикацию.

Интерфейс утилиты выполнен в темной теме с использованием векторной графики GDI+ (Anti-Aliasing) для сглаживания элементов управления.

---

## Основные возможности

### 🔋 1. Обслуживание аккумулятора (Battery Care)
* **Аппаратные лимиты**: Переключение прерывания заряда батареи на уровне EC-контроллера.
* **Пороги заряда**: Pill-образные кнопки для установки лимита на **50%, 60%, 70%, 80%, 90%, 100%**.
* **Сохранение состояния**: Запись настроек при изменении лимита.

### ⚡ 2. Переключение режимов производительности
* **Три профиля питания**:
  * 🌿 **Эко-режим (Eco)**: Снижение частот процессора и энергопотребления для бесшумной работы.
  * 🧠 **Умный режим (Smart)**: Автоматическая регулировка производительности под текущую нагрузку.
  * ⚡ **Турбо-режим (Turbo)**: Работа процессора на максимальном теплопакете.
* **Цветовая индикация**: Выделение активного режима соответствующим цветом.

### 🔔 3. Экранные оверлеи (OSD Layered Popup)
* Отображение полупрозрачного окна OSD при переключении режимов кнопками, из трея или горячими клавишами.
* **Отображение состояния**: Сглаженные с помощью GDI+ иконки режимов (лист Эко, чип Smart, молния Turbo, статус батареи) на градиентном фоне.
* **Эффект затухания**: Попиксельное скрытие оверлея с использованием альфа-канала (`UpdateLayeredWindow`).

### 🌐 4. Локализация интерфейса (Localization Engine)
* Перевод интерфейса, всплывающих окон OSD, сообщений об ошибках и меню системного трея на три языка:
  1. **Русский**
  2. **English**
  3. **中国** (Китайский)

### 💻 5. Системная интеграция
* **Автозапуск с Windows**: Запись параметра в реестр для автоматического старта утилиты.
* **Сворачивание в системный трей**: Скрытие окна в трей при закрытии приложения для непрерывного фонового мониторинга.
* **Четкость иконок**: Загрузка ресурсов через `LoadImage` с использованием системных метрик (`SM_CXICON`/`SM_CXSMICON`) для исключения размытия значков.
* **Отрисовка без мерцания (Flicker-Free)**: Использование двойной буферизации (Double Buffering) и стиля `WS_CLIPCHILDREN` для предотвращения мерцания кнопок при наведении курсора.

## Глобальные горячие клавиши (Hotkeys)

* **`Ctrl + Alt + P`**: Циклическое переключение тепловых режимов (`Эко` ➔ `Умный` ➔ `Турбо` ➔ `Эко...`) с выводом OSD.
* **`Ctrl + Alt + B`** (Резервный вариант: **`Ctrl + Alt + L`**): Включение и отключение обслуживания батареи с выводом OSD. 
  *(При занятости сочетания с 'B' другими процессами регистрируется клавиша 'L')*.

## Сборка и компиляция

### Системные требования:
* Операционная система Windows 10 или Windows 11.
* Visual Studio 2022 / Build Tools 2026 (Toolset **`v145`** или аналогичный).
* Драйвер доступа к портам **WinRing0x64.dll / WinRing0.dll** в одной папке с исполняемым файлом.

### Сборка через MSBuild:
Для компиляции Release-версии выполните команду в консоли PowerShell:
```powershell
& "C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\MSBuild\Current\Bin\MSBuild.exe" xiaomi_corecharge.sln /p:Configuration=Release /p:Platform=x64 /p:PlatformToolset=v145
```
Исполняемый файл сохраняется по пути: `x64\Release\xiaomi_corecharge.exe`.

## Важные примечания
* **Права администратора**: Драйвер `WinRing0` требует повышенных привилегий для доступа к портам ввода-вывода.
* **Совместимость**: Утилита работает на устройствах, поддерживающих EC-адреса `0x68` (питание) и `0xA4`/`0xA7` (батарея). На несовместимом оборудовании активен демонстрационный эмуляционный режим.
